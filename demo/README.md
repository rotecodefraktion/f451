# Demo spaces

Content for a demo instance of f451 with clean data. Each folder is one space,
laid out exactly as it lives in its Git repository (`<page>/index.md`,
`.order` files for sibling order):

- `user-guide/` — how to read, write and review in f451
- `developer-guide/` — architecture, local setup and how to extend f451

To use them, push each folder to its own repository on your Forgejo or GitHub
and list the repositories in `F451_SPACES`.

> Page ids must be unique across all spaces of an instance.
