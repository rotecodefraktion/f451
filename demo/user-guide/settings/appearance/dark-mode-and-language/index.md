# Dark mode and language

## Dark mode

The theme toggle switches between light and dark mode at any time without
going into settings. It sits in the top bar for themes that have one;
otherwise (the Editorial default) at the foot of the page tree. In [[my-settings]] every design
value is kept for **Light** and **Dark** separately.

## Language

The language switcher — in the top bar, or at the foot of the page tree
when there is no top bar — lets you choose between **German** and
**English** for the interface. Page content keeps whatever language
it was written in (each page's frontmatter records its own `lang`);
switching the interface language does not translate page content.
