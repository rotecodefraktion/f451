# Playground

This space is yours to try things out. Everything else in this demo is
read-only; here you can create pages, edit them, open a review and approve
it — the full workflow from the [User Guide](https://github.com/rotecodefraktion/f451/tree/main/demo/user-guide).

> [!NOTE]
> The demo is reset every night. Whatever you write here disappears then.

## Things to try

1. Click **Edit** on this page, change a sentence and save.
2. Type **/** in the editor and insert a callout, a draw.io diagram or an
   Excalidraw sketch.
3. **Request review**, then **Approve & merge** — and look at the pull request
   that appeared in Forgejo.
4. Create a new page with **+** in the sidebar, from the **Process runbook**
   template if you like.
5. Pick a **classification** in the editor, next to **Archive**. Try
   **Strictly confidential** and search for the page afterwards.
6. Pages here are versioned: tick **Freeze as release** when you approve,
   change the page again, and open the frozen release from the header line.
