Deployment

Standardprozess für das Ausrollen neuer Plattform-Versionen in die Produktionsumgebung — verbindlich für das Betriebsteam.

Überblick

Deployments erfolgen ausschließlich über die CI-Pipeline und werden aus dem Branch main ausgelöst. Jede Freigabe durchläuft die drei Zustände working, review und released, bevor eine Version produktiv geht.
